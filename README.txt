# Digital Business Passport V1
Halaman utama statis untuk Prodi Bisnis Digital Universitas Darwan Ali.

## Cara menjalankan
1. Buka `index.html` di browser.
2. Jika ingin online, upload folder ini ke GitHub Pages.
3. Data mahasiswa dan QR Passport akan ditambahkan pada tahap berikutnya.

## Struktur
- index.html
- style.css
- script.js
- assets/unda-logo.png
